Gate 4 · Mandatory Rule

The Subtraction Rule

Before adding any control, row, badge, or tab to an existing screen, the phase doc must name explicitly what gets removed, merged, or collapsed so the screen stays calm. One primary action per screen, zero nested cards, and zero multi-sentence prose walls above data.

Offline Mockup Before Code Verify Light & Dark (@iammrduncan/magnesium thermite.css) at 1440px & 390px with realistic long names, empty, active, and error states. Mock up two directions side-by-side when layout trade-offs are non-obvious.
IA QUESTION 1 · PLACEMENT

Single Named Home

Name the single core slot (Home, Compute, Knowledge, Campaigns, Setup) or one of the 6 plugin slots that owns the UI. Core nav never adds a 6th core slot.

IA QUESTION 3 · ONE HOME, ONE WORD

Single Vocabulary

Every fact has one primary home (other screens link in one line) and uses design-plan.md's exact vocabulary: machine › device, Needs you, Attempt, Verdict.

IA QUESTION 4 · EDGE STATES

Empty, Dense & Error

Define what a first-time user sees, what auto-hides when empty (like Home's Readiness Strip), and the exact actionable error sentence when a check fails.

Section 6 · requirements.md & phases/_template.md

Requirements Intake & Phase Template

Thermite v1 replaces v0.x's 272-file .goal graveyard with one living requirements ledger wired directly into Gate 1, temporary single-file phase briefs, and honest Gate 6 close-outs.

STEP 1 · RAW INTAKE Issue / PR / Field Pain Mined from 51 public issues (#20–#116), 67 PRs (14 external contributors), and multi-day field runs. Zero speculative ideas.
STEP 2 · LIVING CONTRACT REQ-NNN in requirements.md 46 active REQs (45 Accepted, 1 Proposed) + 10 DROP-* rules mapped to Waves v1.0–v1.3 and Goals 1–14. Never renumbered.
STEP 3 · BUILD BRIEF phases/<slug>.md Copied from phases/_template.md. Completes Gates 1–4 + mockup, locks Open Questions & Gate 5 Sign-Off, then runs via /goal.
STEP 4 · HONEST CLOSE-OUT phases/_completed/ Records plan-vs-built deltas & actual LOC, updates REQ-NNN → Verified, passes owner Human checks, and git mvs in one commit.
