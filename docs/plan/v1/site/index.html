End-to-End Capabilities & User Journeys

Every pain point audited in v0.2—20-minute installs, burned join tokens, multi-file boilerplate, hardcoded owner walls, synchronous SQLite stalls, and brittle live sync—has a locked architectural answer in v1.

Control Install (setup.sh)

< 2 min

Mirrors fxbot's host command & systemd update watcher. Zero manual secret init, zero 7-file Compose override chains, zero cloning the repo.

curl -fsSL https://usethermite.com/setup.sh | sudo bash
  1. 1
    Non-destructive preflight: checks OS/arch, systemd, ports (8800, 4222), disk (≥ 3 GB), and rejects snap-Docker before writing anything.
  2. 2
    3-service Compose (~55 lines) + host runner: starts control (:8800 + /nats WS proxy), nats (JetStream TLS :4222), and db (pgvector/pgvector:0.8.x-pg18-trixie), plus auto-enrolled host thermite-runner.service (never mounts container socket inside Compose).
  3. 3
    Atomic rollback updates: thermite-control.path watches /var/lib/thermite/control/requests/*.json so UI upgrades snapshot PG, wait for health, and auto-rollback on failure.
  4. 4
    3-step resumable first-run UI: (1) Owner username + password cookie (optional THERMITE_NO_AUTH_LOOPBACK=1 for dev) → (2) Provider catalogue (OAuth, API key, or keyless LAN HTTP) with live test → (3) 1-click bundled 60s matmul-cpu sample or own repo.

Remote Machine Join (herdr/rex style)

~30 sec

Works identically on Linux bare metal/VMs (systemd) and macOS Apple Silicon (launchd + device-metal / MLX on day one).

# With CLI installed:
thermite join https://control.example.com --token thm_join_example

# Or bootstrap thin runner + join in one paste:
curl -fsSL https://usethermite.com/join.sh | sh -s -- \
  https://control.example.com --token thm_join_example
  1. 1
    Preflight before token burn: verifies hardware and transport first; 15-minute token is not consumed until cryptographic enrollment succeeds.
  2. 2
    Auto hardware probe: loads device-cpu, device-cuda (NVIDIA + CDI), and device-metal (Apple Silicon GPU + unified memory + MLX).
  3. 3
    Local Ed25519 NKey & dual transport: mints runner.nk (0600; private seed never leaves host), calls POST /v1/machines/enroll, receives scoped NATS user runner:<m> over TLS :4222 or wss://<control>/nats.
  4. 4
    Wall self-test & live appearance: starts OS service, passes wall.selfTest(), publishes 5s heartbeats, and appears immediately in Compute (machine › device).

Minimal 7–12 Line thermite.yaml

Automatic baseline A/A noise calibration, interleaved A/B + B/A timing blocks, GPU-drain checks, and hidden held-out cases snapshotted outside worker zones.

Sane defaults: editable_paths: ["**"], host-proportional limits (75% runner RAM, 5× baseline time), zero default turn/trial/spend caps, and identical core/api actions across UI, CLI (thermite init / run --dry-run), and MCP.

Bundled git-sync Plugin (All 4 Modes in v1.0)

Decision #9

Control holds one bare Git mirror and sealed push credentials (runners never hold push tokens). On every attempt.promoted event, the bundled default-on git-sync plugin executes the campaign policy and emits git.sync_finished.

Control-Plane 3-Tier WallPlugin Stack (All in v1.0, Proof-Gated by wall.selfTest())

Goal 0's isolation spike ruled NO-GO on running full zones inside V8 isolates/WASM (native libfx N-API & JSPI limits, memfs OOM on large C++/Rust repos). Instead, trusted libfx + sealed secrets stay on Control host while untrusted tools and CLIs run behind swappable walls.

Tier 1: wall-tools Default

Path-jailed git worktree (O_NOFOLLOW + realpath), structured file tools, SSRF-blocking fetch, plus in-process virtual bash (bashkit-wasm / just-bash) for piped grep|awk|sed|jq with zero OS process spawn.

Tier 2: wall-os < 10ms

Linux bubblewrap + Landlock + seccomp + --unshare-net host proxy; macOS Seatbelt + host proxy; wall-container fallback. Enables local python3/rg and external CLIs (claude, agy).

Tier 3: wall-microsandbox v1.0 Day One

libkrun hardware-virtualized microVMs (< 100ms boot, dedicated guest kernel) on KVM Linux & Apple Silicon HVF, falling back cleanly to wall-container where /dev/kvm is absent.

Two-Layer PostgreSQL 18 Stack

Replaces v0.2's 11,580-LOC / 67-file synchronous SQLite KB (and deletes rig-side SQLite mirrors completely) on one container image: pgvector/pgvector:0.8.x-pg18-trixie (PG-licensed, zero AGPL).

LAYER 1: CORE KB (~900–1,100 LOC · embedder: off default)
Normalized tables (kb_collections with kind: 'campaign' | 'shared', kb_items, kb_versions, kb_chunks, kb_blobs, kb_links, kb_grants, kb_run_scopes). Content-addressed blobs (zero 4× text copies), async NATS heading-aware parent-child chunker, dual tsvector (english + simple) + pg_trgm, compaction transcripts excluded from default search, pooled async PG (max ≥ 8), pure Sans-I/O query parser + RRF.
LAYER 2: knowledge-semantic PLUGIN (~450–650 LOC · 1-click toggle)
Owns plugin_knowledge_semantic.chunk_embeddings with lazy partial halfvec HNSW per (model, dims) + hnsw.iterative_scan = 'relaxed_order', async batch embedder (local ~450 MB llama.cpp EmbeddingGemma 2 / Qwen3-Embedding or remote), cosine-gated RRF (k = 60). Seamless fallback to Core FTS when off or down.

live-publish (thermite live)

Wave 3 · v1.2

Replaces v0.2's brittle multi-agent folder-sync deployment with a per-run boolean toggle backed directly by NATS.

  • Privacy by construction: reducer emits sanitized projections to t.live.<run>.> only when run.live === true.
  • NKey isolation: external relays authenticate as live-reader, physically unable to subscribe to private runs or publish into LIVE.
  • Zero core bloat: registers live.toggle, live.status, public SSE/JSON via route(), or forwards to live.usethermite.com.

web-pairing & PWA

Wave 3 · v1.2

Ported directly from fxbot/plugins/web-pairing for mobile & remote browser control at web.usethermite.com with zero VPN or port forwarding.

  • Encrypted P2P: Noise + Ed25519 keys, QR + 6-digit SAS verification, on-demand signaling relay WebSocket only when paired devices/tickets exist.
  • Safe loopback bridge: proxies HTTP/SSE/WS over WebRTC data channels to t.localUrl tagging x-thermite-web-pairing (rejected by pairing admin routes).
  • Installable mobile app: enables VitePWA (registerType: "prompt") atop v1.0's inline splash & safe-area insets.

distill-jsonl

Wave 3 · v1.2

First-class fine-tuning dataset distillation pipeline over durable run traces, prompts, diffs, verdicts, tool calls, and learnings.

  • Export formats: SFT trajectories, preference pairs (promoted vs. rejected), and full tool-call traces.
  • Filter & redact: filterable by outcome, champion lineage, and role; secret-redacted streaming downloads via route().
  • Zero core schema changes: registers distill.export & distill.preview over read-only SQL views and optional plugin_distill_jsonl presets.
